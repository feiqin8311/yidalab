## 发给试用用户（复制下方）

【YidaLab 内部试用邀请】

我们开始小范围试用 YidaLab（智能工作台），希望你帮忙点踩主流程。

**怎么进**

- 推荐：钉钉 → 工作台 → 打开「YidaLab / 对应应用名」（一般会自动登录）
- 备选：浏览器打开 `https://你的域名` ，用我们发你的账号登录

**建议试这些**

1. 打开系统并完成登录
2. 随便聊一轮，看回复是否正常
3. 如有机器人：单聊发一句话，再发 `/new` 看是否新开话题
4. 有任务权限的话：建一个任务并设近一点的定时，观察是否会跑

**请注意**

- 这是**内部预览**，功能可能变，稳定性不按正式产品承诺
- 数据以运维备份为准；重要内容请另存
- 出问题请发：**时间 + 你怎么操作的 + 截图 + 钉钉 / 浏览器环境**，发到 xxx 群 / 联系人

感谢帮忙试用。
